# Archive: the Godot era (retired)

This folder holds the original **Fortress Command** prototype, built in Godot 4, and its early design notes. It is no longer developed. The live game is the web version in [`../../web/`](../../web/).

The web game was ported from this project, so some comments in `web/js/` still mention the `.gd` files they started from. Those files are in `godot/` here.

| Path | What it is |
|------|------------|
| `godot/` | The Godot 4 project (GDScript, built-in scene system). Open `godot/project.godot` in Godot 4 to run it. |
| `SPEC.md` | The design specification for the Godot build. |
| `foundation.txt` | The early design brief for a single-file browser version. |
| `entities.txt` | Early unit and building definitions. |

The branch [`archive/godot-final`](https://github.com/infinitybiscuit/fortress-command/tree/archive/godot-final) is a snapshot of the whole repo just before the Godot project moved here.
